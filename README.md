# Git Practice Lab

A hands-on playground covering essential Git and GitHub workflows used in real-world software development.

## Folder Structure

- **`auth/`** – Login logic and security patches
- **`config/`** – App configurations & conflict resolution testing
- **`core/`** – Core application features & entry points
- **`modules/`** – Modular components (Octopus merge practice)
- **`services/`** – Payment & analytics services (Rebase practice)
- **`ui/`** – Navbar, sidebar, and footer (Squash merge practice)
- **`playground/`** – Initial practice and test files

## Concepts Practiced

1. **Merge Strategies:** Fast-forward, 3-Way, Squash, and Octopus merge
2. **Conflict Resolution:** Handling divergent branch edits
3. **Linear History:** `git rebase` vs `git merge`
4. **Selective Commits:** `git cherry-pick`
5. **Rollbacks & Fixes:** `git revert`, `git reset`, and `git commit --amend`
6. **Workspace Hygiene:** `git stash` and `.gitignore`
7. **Remote Workflows:** Branch push, deletion, and remote link management
